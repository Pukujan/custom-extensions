# Custom Extensions

Durable collection of independently loadable Brave/Chromium extensions.

## Extensions

- [`youtube-focus-lock/`](youtube-focus-lock/) — Windows 10/11 + macOS Brave YouTube blocker with an 11:00 AM–12:00 PM access window, 60-minute removable burn-in, shared 120-problem Python challenge runtime, and staged OS-specific anti-removal policy.
